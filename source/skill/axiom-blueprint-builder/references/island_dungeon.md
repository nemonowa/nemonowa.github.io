# 浮遊島＋聖樹ダンジョン（地下と幹の中を攻略する）

雛形：`examples/floating_island_dungeon/island_dungeon.py --theme spring|summer|autumn`（素材・意匠は `themes.py`）。
同じ形で **春（桜）／夏（ひまわり）／秋（楓）** を作れる。新しい季節は `themes.py` の SPRING をコピーして値を替える。

## 1. 全体の寸法（ワールド座標。広場の床 y=0）
| 要素 | 値 |
|---|---|
| 島 | 6つの楕円の合成 `field`、底は逆円錐（深さ ≒ 30·v^0.62、中央で約33）＋鍾乳石。範囲 x -62..62, z -62..61 |
| 広場 | 中心 (0,4)、半径18。参道は z 21〜47（x ±2）、月門は z=28（縦の輪、内半径5.7・外半径8、中心高6.6） |
| 聖樹 | 幹の軸 (0,-27)、高さ46、半径 4.3＋2.0(1-t)^1.5＋3.0e^(-y/3.2)。樹冠は『殻』7個＋6個 |
| 遺跡 | x 21..37, z -11..5。柱 5×2 本・奥の壁・祭壇と浮かぶ『心』 |
| 小島 | 6つ（半径5〜9）。提灯の綱で本島と結ぶ |
| 背面レリーフ | z=-72 付近（月／モミジ／ひまわり）。星・光の粒は範囲を避ける |

## 3. 作り方の順序
地形 → 広場・門・立石・遺跡 → 聖樹（幹・根・枝・樹冠の殻）→ `Dungeon` の `section()` で部屋を掘る（tree/root/stone）→ `line_sections()` で区画ごとの素材で内張り → ハシゴ・宝箱・スポナー・照明 → 樹冠の間（葉を抜く→床→隙間を塞ぐ）→ `check_leaks()==0` と `solve()`（扉1/1・宝箱13/13）→ 小島・レリーフ・飾り → BE入り/BEなし保存。
`Dungeon.section/line_sections` は今回追加。幹の内部は木材、迷路は泥と根、地下は石、と素材を変えられる。戻り値の『突き出しセル』が幹の外へ出ていないかの目安（2個＝扉枠）。

## 4. 設計上の要点と失敗談（根拠は実測）
- **幹の内部を使うには幹を太く直立に**：最小半径 4.3（ふくらみ ×0.88 で 3.8）。梯子の縦穴は中心から 2、壁（内張り）で 3 → 余裕 0.8。**曲がる幹だと縦穴が外へ出る**ので直立にし、うねりは枝に任せる。半径 4.3 未満だと小部屋 r=2.2 の内張りが幹の外に突き出す。
- **樹冠の殻は中が空洞**（inner=0.5）。そこが樹冠の間になる。床の高さ＝幹の頂部（y=Y0+H）で空洞の底とほぼ一致。
- **梯子の真上の葉も抜く**：最初、梯子のセルだけ『床を張らない』つもりで列ごと `continue` して葉が残り、**宝箱に到達不能**になった（solve が検出）。縦穴の柱は床は張らず空間は抜く。
- 梯子の裏に壁が要る：ホール内（円盤が壁を含まない所）では柱を1本置く。ハシゴは `facing`=壁と反対向き。
- **トラップドアの蓋は BFS が通れない**（検証が『到達不能』になる）。ゲーム内では開けっぱなしの穴＋ハシゴが確実。蓋を使うなら検証用の別処理が要る。
- 螺旋の `y0` は**床ブロックの高さ**（歩く高さ-1）。着地は `y0-n`。迷路の入口列を中心に合わせるには cx を奇数セル数にする（入口 idx=cx//2）。
- 溶岩の飛び石は1マス空け（ジャンプ可）。溶岩は床ブロックと面一。2幅の溶岩は『中間の石』を置く。
- 近道の扉は**両側に壁レバー**（`door_levers`）。片側だけだと反対側から開けられず帰れない（実機で指摘された）。BFS は『レバー到達→扉が開く』を反復して判定する。
- 葉をウール等で作るとき（秋）は殻に渡すプロパティを {} に（LEAF を渡すと不正）。葉ブロックなら persistent=true の `LEAF`。
- ひまわりは二段の植物（half=lower/upper）。下の足場が壊れると消えるので地面に直置き。絨毯・ろうそくは `candles/lit/waterlogged`。
- 蛍（end_rod）はダンジョンの空洞（`dg.D`）に置かない。ビューアの HTML は見える面だけなので 8 作品入れても 2.3MB。
- 宝箱（ルートテーブル）・スポナーの BlockEntities は**実機確認済み**（BE入りを主に渡す。BEなし版は頼まれた時だけ）。スポナーの湧き箱は壁を貫通する。

## 6. 返答の書き方
サイズ → 意匠（外→内）→ ダンジョンの攻略順（入口→分岐→最深部→帰り道）→ 検証結果（宝箱n/n・扉・密閉）→ 同梱物（BE入り/BEなし/マップ/コマンド）→ 注意点（BE実機未確認、スポナーの貫通、植物ブロックの性質、ブロックの当て込み）。ビューアのアーティファクトは同じ URL を更新し、新作を先頭に。
