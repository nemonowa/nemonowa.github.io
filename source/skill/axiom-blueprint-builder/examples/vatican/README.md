# バチカン（サン・ピエトロ大聖堂と広場）1ブロック=1m

`python3 vatican.py OUT_DIR` → `Vatican_StPeter_1m.bp`（書見台の本入り）/ `_noBE.bp` / `vatican_book_commands.txt`。約43万ブロック、490×142×274、生成は約25秒。

- 聖堂本体は `outer()`/`inner()` の解析的な立体を**厚さ2の殻**にして作る（見えない芯を置かない）。内装（床の大理石・金の格天井）は殻のセルが内部に面するかで材料を分ける。
- ドームは尖頭気味の回転体を `smooth_heightfield` で階段・ハーフにし、16本のリブを白に置換。ドラムは16組の対の円柱、アティック、ランタン、十字架（床から約136m）。
- 広場は楕円（内側の半径 80×104）からのオフセット `ell_o()` で柱廊・舗装・屋根を決める。柱は4列×各腕36本を放射状にそろえる。
- 検証：広場→正面の段→前廊→身廊→交差部・西アプス・北翼廊・側廊まで歩行BFSで到達。
- 省略・近似：内部の礼拝堂と墓碑、ミケランジェロの壁面の細かな凹凸、ベルニーニ柱廊の端部の神殿正面、使徒宮殿とシスティーナ礼拝堂は外形のみ。
