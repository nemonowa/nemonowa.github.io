# くさび形の巨大宇宙戦艦（オリジナル設計、1ブロック≒5m）
`python3 wedge.py [出力ディレクトリ]` → `Wedge_Warship_5m.bp`（約9.2万ブロック、201×88×342）。
- 既存作品の複製ではなく、「くさび形の巨大艦」というジャンルのシルエットを使った**オリジナル**。名称・標章は使わない。
- 作り方: **列ごとの上面/下面の高さ表**（TOP/BOT）を先に計算し、上面と下面の殻1枚＋段差の側壁だけを置く。厚みのある塊を埋めない（埋めると数十万ブロックになる）。
- 段差（第1段・第2段・塔の台座・中央の溝・キール）は高さ表への加減算で表現。窓の灯りは段差の側壁に sea_lantern。
- 艦橋塔（先細りの首＋段状の頭部＋窓列＋球状ドーム2つ）、エンジン5基（黒い縁＋発光面＋ガラスの噴射光）、艦底の格納庫（開口＋壁＋天井照明）。内部は空洞。
