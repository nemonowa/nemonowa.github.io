# ISS × スペースシャトル 合体シーン（1ブロック=1m）
`python3 combo.py [出力ディレクトリ]`。`examples/iss` と `examples/shuttle` を実行して Build を取り出し、合成します（exec で保存前まで走らせる方式）。
- 接続: シャトルの ODS を Harmony 前方 PMA-2 に（STS-134: PMA-2=Harmony 前方）。姿勢は「尾部=地球側、貨物室=ISS側」（STS-110 事前報道）。
- **90°回転の注意**: 軸の入れ替え `X=ox, Y=oz-21, Z=56-oy`。**階段・はしご・ドア・看板・書見台は向きが表せない**ので、外観用に外す（階段は角を空ける、ドアは壁で埋める）。シャトル船内は歩けなくなる（ODS までは歩ける）。
- 合体のため Dragon と Cygnus を外す。重なりセル数を表示して衝突を検出。
- 検査: 単体版の許可箱＋ODS を追加して `check_interior`（密閉・到達）。
