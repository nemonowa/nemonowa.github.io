# スペースシャトル オービタ（1ブロック=1m）
`python3 shuttle.py [出力ディレクトリ]` で `Shuttle_Orbiter_1m.bp`（本・看板BE入り）/`_noBE.bp`/`shuttle_books_commands.txt` を生成し、操縦室とODSの密閉・接続を検査します。
- 約 23×19×40、2,104ブロック。+z=機首、+x=左舷、胴体中心 y=0（幅7、貨物室内寸5）。
- 作り方: 胴体は**断面表 P[z]=(半幅,上端,下端)＋超楕円**で外形を作り、操縦室は6近傍の**侵食**で内部を抜く（貨物室は箱を抜いて上を開放）。翼は前縁・後縁を x ごとの表で。垂直尾翼は y ごとに前縁/後縁を計算。
- 歩ける: 左舷ドア→ミッドデッキ→はしご→フライトデッキ、ミッドデッキ奥のハッチ→ODS（ISS接続装置）→はしごで天頂のドッキングリングへ。
- 寸法: 全長37.24m・翼幅23.79m・機体幅6.9m・貨物室18.38×4.57m（NASA/ESA 資料）。ノズルは機体37の外へ3突出。
- 近似: 翼平面形、アームは立ち上げ姿勢、ODSの位置と形、耐熱タイルの個々は省略。
