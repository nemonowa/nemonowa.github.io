# 浮遊する和の島（大規模プロジェクトの実例）
参考画像（空に浮かぶ4島：五重塔・東屋・朱の社殿・蔵）から、内装つきの建築と地下ダンジョンまで一気に作った構成例。
- `world.py` 島の地形（ブロブ合成＋深さ＋縁の葉・蔓）と平坦化/丘
- `pagoda.py` 五重塔（縮尺：1層=6、壁半幅 7/6/6/5/5、軒の出3、`hcap`）＋全階の内装
- `buildings.py` 社殿（入母屋+唐破風）・東屋（囲炉裏）・蔵（ロフト）・小堂・手水舎・太鼓橋
- `dungeon.py` 地底寺院（1階5室＋2階ボス闘技場＋宝物庫）。※ `scripts/dungeon_kit.py` 登場前の独自実装。新規は kit を使うこと。**扉のレバーが片側のみ・床置きの古い作りなので、そのまま真似しない**（kit の `door_levers` を使う）
- `main.py` 組み立て（道・水・建物・植栽・接地チェック・ダンジョン・BlockEntities の書き出し）
実行: `python3 main.py out.bp [out_nbt.bp]`（2本目を渡すと宝箱ルートテーブル/スポナー入り版も出力）
設計の根拠は `references/architecture.md` `references/dungeon.md` を参照。
